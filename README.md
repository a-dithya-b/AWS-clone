# CloudLearn (working name)

A free, open-source, full-stack AWS learning simulator. Services such as IAM and SQS are mocked by
real backend logic, so beginners can learn hands-on with no AWS account, credit card, or surprise
bills.

> CloudLearn is an independent educational project and is not affiliated with, endorsed by, or
> sponsored by Amazon Web Services.
